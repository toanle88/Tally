## Reproducible commands

```bash
pnpm install --frozen-lockfile
pnpm --dir web install --frozen-lockfile
make api-ts-generate
make api-ts-check
pnpm --dir web run build
```

The TypeScript wrapper bundles the multi-file OpenAPI source with Redocly
before invoking Hey API. The generated client uses the bundled Fetch runtime;
no separate `@hey-api/client-fetch` package is required.

- OpenAPI lint passed.
- Two temporary generations produced the same 16-file inventory.

- The generated SDK exports `glGetPostingGateStatus` and the other contract operation IDs.
- Generated output contains the local bundled Fetch client and no external
  `@hey-api/client-fetch` import.
- Temporary TypeScript assertions passed for `Money`, nullable `processId`,
  optional pagination/error fields, typed operation functions, and typed
  success/error responses.
- The committed frontend TypeScript/Vite build passed.
