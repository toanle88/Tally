# TALLY

## A finance platform built to learn by doing

TALLY is a local-first finance platform and solo, part-time learning project. It explores how domain language, accounting integrity, modular architecture, and operational evidence fit together in a working product.

The repository’s specifications are the authority; this site is a concise public guide to the thinking and current progress.

## Explore TALLY

- [Architecture](/architecture): the approved modular-monolith shape and ownership boundaries.
- [Roadmap and progress](/roadmap): milestones, stopping points, and current delivery evidence.
- [Local development](/development): the commands used to build and test the repository.
- [Finance integrity](/finance-integrity): the principles that protect established financial facts.
- [Learning notes and decisions](/learning-notes): practical lessons and selected design choices.
